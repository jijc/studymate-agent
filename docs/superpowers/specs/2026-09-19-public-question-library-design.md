# StudyMate 公共题库静态闭环设计

## 目标

把当前偏“练习套题市场”的题库页改造成网站内置的 IT 面试知识库，让用户完成“查找技术方向 → 收藏常用知识库 → 进入题库 → 选择题目 → 查看答案、解析、代码和面试技巧”的学习闭环。

## 产品边界

- `我的题库`：后续承载根据简历、JD 和薄弱点生成的专属题库，本次不展开。
- `题库`：网站整理的 Vue、React、Java、Python 等公共 IT 面试知识库，是本次开发重点。
- `练习记录`：记录用户真实答题和 AI 评分，本次不展开。
- 公共题库用于查阅和理解，不展示练习难度、得分、题型筛选或“开始练习”。
- 本次只实现前端静态数据与本地交互，不请求接口，不持久化收藏状态。

## 公共题库首页

路由保持 `/questions`，继续复用 `SidebarPageLayout`、`PageSidebar`、统一 Header、背景和设计 Token。

页面结构：

1. 紧凑标题区：`IT 面试知识库` 和一句用途说明。
2. 单一搜索框：高度约 48px，只搜索知识库名称、描述和知识点；不再提供分类标签、下拉筛选和网格/列表切换。
3. `我的收藏`：只在存在收藏时显示，收藏的知识库自动置顶；默认静态状态展示 React、Java、Python。
4. `全部知识库`：排除已收藏项目后，按数据中既定顺序排列。
5. 知识库卡片只展示技术图标、名称、覆盖内容、一个题目数量、收藏按钮和“进入题库”。

收藏交互：

- 点击空心书签后，卡片从“全部知识库”移动到“我的收藏”末尾。
- 点击实心书签后取消收藏，卡片回到“全部知识库”的原始顺序位置。
- 收藏按钮提供明确的 `aria-label` 和 `aria-pressed` 状态。
- 不创建独立“收藏夹”页面。

搜索交互：

- 输入时即时过滤两个区域中的知识库。
- 搜索命中收藏项时仍保留在收藏区域；其余命中项显示在全部知识库区域。
- 无结果时显示简洁空状态和清空搜索按钮。

## 知识库详情页

新增 `/questions/:libraryId` 静态路由，延续同一侧边栏与页面宽度。

桌面端采用主从结构：

- 顶部返回公共题库，并展示当前技术名称、简介和题目数量。
- 左侧为章节和题目目录，可搜索当前知识库题目。
- 右侧展示当前题目内容。
- 移动端改为单列：题目目录位于内容上方，避免横向滚动。

题目详情包含：

- 题目和知识点说明。
- 参考回答。
- 原理解析。
- 示例代码；没有代码的题目不显示代码区。
- 面试回答技巧。
- 常见追问。
- 上一题、下一题切换。

答案默认折叠，用户点击“查看参考答案”后展开完整学习内容；切换题目时恢复折叠，避免答案直接暴露。

## 静态内容

- 首页至少展示 React、Vue、TypeScript、Java、Python、Go、Node.js、数据库、计算机网络、操作系统和系统设计。
- 每个知识库均可进入详情模板，不出现空白或无效入口。
- 静态详情数据提供有代表性的题目目录；React 题库提供完整的答案、解析、代码、技巧和追问内容，用于验证完整页面层级。
- 题目总数是内容规模说明，卡片只出现一次，不再出现重复数量。

## 组件边界

- `QuestionsPage`：管理搜索、收藏和排序，组合首页区域。
- `QuestionLibraryHero`：标题和紧凑搜索。
- `FavoriteLibrarySection`：收藏区域及空状态控制。
- `QuestionLibraryGrid`：按顺序渲染知识库卡片。
- `QuestionLibraryCard`：单张知识库卡片与收藏操作。
- `QuestionLibraryPage`：详情页状态和题目选择。
- `QuestionDirectory`：章节与题目目录。
- `QuestionStudyContent`：题干、折叠答案、解析、代码、技巧和追问。
- `QuestionSidebar`：继续复用共享侧边栏结构，不复制布局。

## 响应式与视觉

- 保持已经确认的方案 1：暖橙色、米白背景、轻边框、弱阴影和圆角。
- 收藏卡片使用轻微暖色边框区分，不增加醒目的营销标签。
- 首页知识库网格为大屏四列、中屏两列、小屏一列。
- 搜索框保持紧凑，不使用大面积 Hero 插画或笨重控件。
- 详情正文控制阅读宽度，代码区允许横向滚动但页面本身不产生横向滚动。

## 验收标准

- `/questions` 不再出现分类按钮、筛选下拉、难度标签和“开始练习”。
- 每张卡片只显示一次题目数量。
- 收藏和取消收藏会正确移动卡片，取消后恢复原始顺序。
- 搜索能过滤知识库并显示无结果状态。
- 所有知识库卡片均能进入详情路由。
- 详情页可选择题目、展开答案、查看解析/代码/技巧/追问，并切换上一题和下一题。
- Header、侧边栏、页面宽度和响应式行为与整站保持一致。
- 自动化测试、Lint 和生产构建通过，并完成真实浏览器验收。
