# StudyMate 统一登录设计

## 目标

将当前“登录 + 独立注册”改为统一账号入口：默认使用手机号验证码登录，未注册手机号验证成功后由后端自动创建账号；当前阶段只实现静态页面与本地校验。

## 已确认规则

- 删除独立注册入口和注册表单。
- 删除邮箱登录；邮箱未来只在个人中心绑定。
- 登录卡片提供“验证码登录”和“密码登录”两种方式，两者共用手机号。
- 验证码登录展示“未注册手机号验证后将自动创建账号”。
- 密码登录展示手机号、登录密码和“忘记密码”入口。
- 两种方式都必须同意用户协议和隐私政策。
- 不接认证接口，不修改后端，不开发个人中心。

## 组件边界

- `AuthCard`：登录卡片外壳、品牌标题，仅承载一个 `LoginForm`。
- `LoginForm`：管理验证码/密码登录方式、字段状态和本地校验。
- `AuthField`：继续负责通用输入框。
- `VerificationCodeButton`：继续负责本地验证码倒计时。
- `RegisterForm`：删除，不保留无引用组件。

## 验收标准

- 页面不存在“立即注册”、注册表单和邮箱登录。
- 默认显示手机号、验证码和获取验证码按钮。
- 可以切换为手机号、密码登录；切换后手机号输入保留。
- 两种方式分别校验当前可见字段与协议勾选状态。
- 验证码倒计时继续可用。
- 前端测试、Lint、生产构建通过。
