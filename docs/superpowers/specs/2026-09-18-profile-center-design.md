# StudyMate 个人中心静态页面设计

## 目标

为登录后的用户补齐头像菜单和个人中心静态页面，使账号信息、求职画像、账号安全和学习通知形成清晰入口，并始终围绕“资料分析 → 专属出题 → AI 评估 → 薄弱点强化”的主任务设计。

## 第一版范围

- Header 头像使用 Base UI Menu 提供下拉菜单。
- 下拉菜单包含用户摘要、个人中心、账号与安全、退出登录。
- 新增 `/profile`、`/profile/career`、`/profile/security`、`/profile/notifications` 四个静态路由。
- 页面复用现有 1480px 宽度、通用暖色背景、橙色 Token、卡片、边框和阴影。
- 表单和开关只提供本地静态交互，不请求接口。

## 不在第一版实现

- 真实鉴权、用户状态和退出接口。
- 头像文件上传、表单保存、短信或邮箱验证码。
- 简历、项目资料、JD 管理。
- AI 分析和题目生成接口。
- Pro 订阅、套餐与账单。

## 头像菜单

- 桌面端触发器显示头像、问候语和下拉图标；移动端只显示头像。
- 菜单顶部展示头像、昵称和脱敏手机号。
- “个人中心”进入 `/profile`。
- “账号与安全”进入 `/profile/security`。
- “退出登录”在静态版本中进入 `/login`，后续由真实登出逻辑替换。
- 点击外部、按 Escape 或选择菜单项时关闭菜单。

## 个人中心信息架构

### 个人资料

- 展示头像、昵称、脱敏手机号。
- 提供更换头像和保存修改按钮，但不执行真实上传或保存。

### 求职画像

- 主目标岗位、当前职级、工作经验、回答语言、核心技术方向、练习难度。
- 明确说明这些信息将与简历、JD 和历史薄弱点共同影响 AI 出题。

### 账号与安全

- 手机号、登录密码、邮箱、登录设备四个状态行。
- 提供更换手机号、设置密码、绑定邮箱、退出其他设备入口，但不执行真实验证。

### 通知设置

- 每日练习提醒、薄弱点专项提醒、周度学习报告、系统通知。
- 使用 Base UI Switch；系统通知保持开启并禁用修改。

## 路由和布局

- `ProfilePage` 根据路由分区渲染对应内容。
- `ProfileSidebar` 同时提供桌面侧栏和移动端横向导航。
- `/profile` 使用登录后 Header 和通用背景。
- 现阶段继续使用项目已有的路径模拟登录状态，不在静态 UI 阶段引入认证上下文。

## 验收标准

- 题库、报告和个人中心 Header 均能打开头像菜单。
- 菜单链接可进入个人中心、账号安全和登录页。
- 四个个人中心路由都能直接访问和相互切换。
- 页面宽度、Header、背景和视觉 Token 与现有页面一致。
- 页面没有简历/JD 上传和 Pro 入口。
- 测试、Lint、生产构建通过。
